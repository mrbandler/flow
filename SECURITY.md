# Security Policy

## Supported Versions

Flow is currently in early development (pre-1.0). No versions are officially supported yet.

## Reporting a Vulnerability

**Do not open public issues for security vulnerabilities.**

Email: <me@mrbandler.dev>

Expected response time: 72 hours

Include:

- Description of vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt and provide a timeline for fixes.
